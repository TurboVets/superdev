The bars that fire before a PR exists.

Review · F1–F11

  • Sibling sweep — one guard, every caller
  • Vacuous-test probe — the test can still fail
  • Transaction shape — atomic or not at all
  • Copy truth and density — no filler
  • Over-engineering — the unused abstraction dies

Security · S-1–S11

  • AuthZ and ownership on every write
  • URL, upload, and HTML stay untrusted
  • PII redacted on the way out
  • Secrets never land in the public skill
  • Full intensity on a one-file guard

What SuperDev will not do.

Merge without an ask A green ladder is not permission to merge. You say the word.

Write a teammate’s GitHub Findings stay in chat as P0/P1. Their PR is theirs.

Skip Path 6 An older Ship, a bot APPROVE, or Docker-down does not skip live QA or smoke.

Ship someone else’s memory state/ and operator.yaml stay on your machine. Empty state is correct on first run.
